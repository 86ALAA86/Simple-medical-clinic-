# Simple Medical Clinic

A lightweight clinic management system built to handle basic patient and appointment operations in a small medical clinic environment. The project is structured using a multi‑layer architecture to keep the code clean, maintainable, and easy to extend.

---

### 📁 Project Structure

```
Simple-medical-clinic-/
│   Simple-medical-clinic-.sln
│
├── DataAccessLayer
│   Database operations, entity models, and data persistence.
│
├── BusinessLayer
│   Core business rules, validation, and service logic.
│
└── PresentationLayer
    User interface for interacting with the system.
```

Each layer is separated to ensure clarity, scalability, and easier debugging.

---

### 🎯 Features

- Patient registration and basic information management  
- Appointment scheduling and tracking  
- Separation of concerns through a 3‑layer architecture  
- Reusable business logic and centralized data access  
- Simple and intuitive UI for clinic staff

### 🚀 How to Run the Project

1. Clone the repository:
   ```
   git clone https://github.com/86ALAA86/Simple-medical-clinic-.git
   ```

2. Open the solution file:
   ```
   Simple-medical-clinic-.sln
   ```

3. Restore dependencies if needed.

4. Set the **PresentationLayer** as the startup project.

5. Build and run the application.

---

### 📦 Architecture Overview

- **DataAccessLayer**  
  Handles all communication with the database, including CRUD operations and entity definitions.

- **BusinessLayer**  
  Contains the logic that connects the UI to the data layer. Ensures data validation and business rules.

- **PresentationLayer**  
  Provides the user interface for clinic staff to interact with the system.
